How to Appeal / Raise a Dispute

What is an appeal?

An appeal allows you to dispute decisions regarding test results, grades, or batch rejections. This ensures transparency and allows for review of lab decisions.

When can I raise it?

  • Incorrect test result or grade assignment
  • Missing or incomplete test data
  • Unfairly rejected batch due to testing errors
  • Other quality assessment concerns
