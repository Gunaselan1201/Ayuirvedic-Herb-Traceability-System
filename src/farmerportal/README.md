# Farmer Portal

Modern Farmer Portal built with React + Vite + Tailwind CSS

## Setup & Run

```powershell
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

The app will be available at `http://localhost:5173`

## Features

- Modern gradient UI design
- Form for adding farmer product information
- Geo-tagged photo upload with preview
- Responsive layout
- Noto Sans font
- Framer Motion animations
- Cross-browser CSS fixes included
