# Manufacturer Portal

Minimal React + Tailwind manufacturer portal with mock state.

## Run

1. npm install
2. npm run dev
3. Open http://localhost:5173

## Login

Use Manufacturer IDs from `src/data/mock.ts`, e.g.:

- MFG001 Dabur
- MFG002 Patanjali

## Notes

- No backend; mock state only.
- Green/blue accents, white background, no icons/animations.
- Accessible labels, keyboard-friendly, responsive two-column forms.
